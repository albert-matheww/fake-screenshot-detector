## 5. Behaviour check outside the literal wording (for the owner of Chapter 6)

- Line 130 states the privacy requirement that the image "must stay in memory and must not be stored". The Flask side satisfies it (item above). Under `docker-compose` the browser reaches the API through `frontend/nginx.conf` `location /api/` with `proxy_pass` and no `proxy_request_buffering off`/`client_body_buffer_size` setting, so nginx will buffer request bodies larger than its in-memory buffer (default 16 KB) to a temporary file in the frontend container. Nothing in the paper or the repo tests this; Chapter 6 section 6.5 ("never writes the image to a path it chose") is true of the application only.
- `analysis.py:164-166` still returns the legacy aliases `fake_score`, `is_fake`, `verdict_text`. Section 3.7 lists the contract without them; `is_fake` is a binary flag (false for suspicious and no_evidence), which sits awkwardly with the "never binary" design principle. Worth a sentence in Appendix A.
